用户：全网搜索在软件加赞助入口该怎么做。

调研结论
- 国内：微信/支付宝个人收款码（最便捷、零门槛；生成时隐藏姓名手机号，
  单笔约 5000 上限）+ 爱发电（按月/单次、后台统计）。
- 国外：Ko-fi / Buy me a coffee（0~5% 抽成）+ GitHub Sponsors 与
  .github/FUNDING.yml（纯 metadata、不进 APK、无权限、不联网）。
- 常见落地：README 收款码图 + 仓库 Sponsor 按钮；APP 内"关于/支持作者"
  放二维码或外链；iOS 因商店政策常隐藏外链，Android 无此限制。

本项目对照与落地
- p195 已有收款码图片（主渠道）；p196 补外链渠道：赞助卡加"赞助链接"
  输入框 + 保存/打开按钮，存本地 sponsor.link，ACTION_VIEW 交系统浏览器，
  无 scheme 自动补 https://。二维码 + 外链并存，覆盖国内/国外习惯。
- 不引入支付 SDK、不联网、不收集捐赠数据。

怎么用：在赞助卡填入你的爱发电/Ko-fi/GitHub Sponsors 地址 → 保存 →
点"打开赞助页"即可验证。收款码仍是点图片更换。
